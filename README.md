# WaveGenFS

Windows 用の低周波信号発生器 (C# / .NET 8 WinForms)。全画面の波形表示に対応。

## 主な機能
- 8 系統の波形合成: サイン / 矩形 / 三角 / ノコギリ / パルス / パルス(+-) / ホワイト・ピンク・M系列ノイズ
- 周波数 (Hz / 周期サンプル数), 振幅 (dB / 値 / %, 極性反転), オフセット, 位相, 出力 ch
- 詳細設定: 遅延, デューティ, 帯域制限 (PolyBLEP), ゲート, 周波数スイープ, AM/FM 変調
- クリップ防止 (合計ピークが 100% を超える振幅は設定不可)
- 出力減衰 1/N (ON/OFF), Volume最大
- FFT用に最適化 (Fs/N の整数倍), Wave1/5 の倍数設定
- WAV 保存 (16/24bit, 32bit float), 設定ファイル (*.wgfs) 保存/読込
- 全画面 (F11), 波形のみ表示 (F12), ホイールで時間軸/振幅軸

## ビルド
```
dotnet build -c Release
```
